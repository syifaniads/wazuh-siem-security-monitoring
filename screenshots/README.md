# Screenshot Evidence

This directory is reserved for **sanitized visual evidence** from the internship project.

Do not upload raw screenshots directly from production or the original report without reviewing them first.

Recommended categories:

```text
screenshots/
├── architecture/
├── wazuh/
├── graylog/
├── misp/
└── alerting/
```

Before publishing an image, redact internal IP addresses, public infrastructure addresses that identify the environment, hostnames, endpoint names, email addresses, credentials, tokens, student/employee identifiers, and raw log content that exposes organizational information.

See [`../EVIDENCE.md`](../EVIDENCE.md) for the recommended evidence set and redaction checklist.
